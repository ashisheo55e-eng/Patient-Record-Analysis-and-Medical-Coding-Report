 **INTRODUCTION** 

Medical coding is an essential process in the healthcare industry that involves converting medical diagnoses, procedures, treatments, and healthcare services into standardized alphanumeric codes. These codes help maintain accurate medical records, support healthcare billing, facilitate insurance claims, and improve communication between healthcare providers and other healthcare organizations.


This project, titled "Patient Record Analysis and Coding Report," focuses on analyzing simulated patient clinical records and assigning appropriate medical codes based on the documented clinical information and established coding guidelines.

The project covers three important medical coding systems:

1.ICD-10-CM (International Classification of Diseases, Tenth Revision, Clinical Modification): Used to identify and classify diseases, medical conditions, symptoms, and diagnoses.

2.CPT (Current Procedural Terminology): Used to report medical procedures, diagnostic services, and other healthcare services performed by healthcare professionals.

3.HCPCS Level II (Healthcare Common Procedure Coding System): Used to identify products, supplies, medications, durable medical equipment, and certain healthcare services not represented by CPT codes.

During this project, approximately 8–10 simulated patient records will be reviewed. Each record will be evaluated based on the patient's symptoms, clinical findings, physician documentation, diagnosis, and treatment plan.

**OBJECTIVES**

1.Review simulated clinical documentation and identify the condition established by the provider.

2.Select an appropriate ICD-10-CM diagnosis code based on the documented specificity.

3.Identify CPT procedure or service codes only when the service is explicitly documented.

4.Identify HCPCS Level II codes for applicable drugs or items, including the correct unit basis.

5.Explain code selection and identify missing details that could affect code assignment.

6.Recognize the importance of using current code sets, official guidelines and complete documentation.

The following records are fictional educational scenarios. Code assignments are based only on the documentation stated in each scenario.

  **Case 01 – Type 2 Diabetes Mellitus** 

**Clinical Record**: A 52-year-old patient attends an outpatient follow-up visit for established type 2 diabetes mellitus. The provider documents type 2 diabetes without known complications. HbA1c testing is performed during the visit. No diabetic kidney, eye, neurological or circulatory complication is documented

 
 **Key findings**: Established type 2 diabetes; no complications documented; HbA1c test performed.
 
 **Code assignment and Rationale**

| Coding System | Code | Description  |
|---------|----------|-----------|
| ICD-10-CM | E11.9  | Type 2 diabetes mellitus without complications. The provider documents type 2 diabetes and does not identify a complication.|
| CPT | 83036 | Hemoglobin A1c test, because HbA1c testing is explicitly documented. |



**Case 02 – Essential (primary) hypertension**

**clinical record**: A 60-year-old patient presents for evaluation of established essential hypertension. Blood pressure is 160/100 mmHg. The provider confirms essential (primary) hypertension and adjusts the patient's antihypertensive medication. A 12-lead electrocardiogram with interpretation and report is documented as performed.

**Key findings**: Provider-confirmed essential hypertension; BP 160/100 mmHg; 12-lead ECG performed and interpreted.

 **Code Assignment and Rationale**
 | Coding System | Code | Description  |
 |---------|----------|-----------|
 | ICD-10-CM | I10 | Essential (primary) hypertension, as specifically documented by the provider.|
 | CPT | 93000 | 12-lead ECG with tracing, interpretation and report, when all components are performed and documented.|

 **Case 03 – Gastroesophageal Reflux Disease Without Esophagitis**

 **Clinical Record**: A 38-year-old patient reports recurrent heartburn and acid regurgitation. Following evaluation, the provider documents gastroesophageal reflux disease (GERD) without esophagitis. The plan includes medication management and dietary advice. No endoscopy or other procedure is documented.

 **Key findings**: GERD without esophagitis confirmed; medication management; no procedure.

**Code assignment and rationale**

| Coding System | Code | Description  |
|---------|----------|-----------|
|ICD-10-CM | K21.9 | Gastro-esophageal reflux disease without esophagitis, matching the documented diagnosis. |

**Coding Note**: Do not assign an Endoscopy CPT code because no endoscopic procedure is documented. If esophagitis is documented, review the more specific GERD code.

**Case 04** – Urinary tract Infection, Site not Specified

**Clinical Record**: A 29-year-old patient reports dysuria, urinary frequency and urgency. Urinalysis is performed. The provider documents urinary tract infection, site not specified. A urine culture is ordered and collected.

**Key findings**: Provider-documented UTI, site not specified; urinalysis and urine culture performed/collected.

**Code assignment and rationale**

| Coding System | Code | Description  |
|---------|----------|-----------|
|ICD-10-CM | N39.0 | Urinary tract infection, site not specified. The documentation does not identify a specific urinary site. | 
| CPT | 81002 | Non-automated urinalysis by dipstick or tablet reagent, without microscopy, if that exact method is documented. |
| CPT | 87086 | Urine bacterial culture, when the culture is performed. | 

**Case 05** – Community-Acquired Pneumonia

**Clinical Record**: A 45-year-old patient presents with fever, productive cough and shortness of breath. Chest examination and imaging support pneumonia. The provider documents community-acquired pneumonia, organism not identified. A two-view chest X-ray is performed. Ceftriaxone 1 g is administered by intramuscular injection in the clinic.

**Key findings**: Pneumonia, organism not identified; two-view chest radiograph; ceftriaxone 1 g IM administered.

**Code Assignment and Rationale**

| Coding System | Code | Description  |
|---------|----------|-----------|
| ICD-10-CM | J18.9 | Pneumonia, unspecified organism, because no causative organism is identified in the documentation. | 
| CPT | 71046 | Chest radiologic examination, two views, as documented. | 
| CPT | 96372 | Therapeutic, prophylactic or diagnostic injection administration, subcutaneous or intramuscular, when the administration service is documented. | 
| HCPCS Level II | J0696 × 4 units | Ceftriaxone sodium injection is reported per 250 mg. A documented 1 g dose equals four 250 mg units. | 

**Case 06** – Acute appendicitis without perforation or gangrene

 **Clinical Record**: A 24-year-old patient presents with right lower-quadrant abdominal pain, nausea and vomiting. Imaging confirms acute appendicitis. The surgeon documents acute appendicitis without perforation or gangrene and performs a laparoscopic appendectomy.

 **Key findings**: Acute appendicitis without perforation or gangrene; laparoscopic appendectomy performed.

 **Code Assignment and Rationale**

 | Coding System | Code | Description  |
|---------|----------|-----------|
| ICD-10-CM | K35.80	| Unspecified acute appendicitis without perforation or gangrene, for the stated documentation; confirm the most specific available code in the current tabular list. | 
| CPT | 44970 | Laparoscopy, surgical, appendectomy, matching the documented laparoscopic approach. | 

**Coding Note**: The diagnosis code must reflect whether perforation, gangrene, abscess or peritonitis is documented. Do not use an open appendectomy code for a laparoscopic procedure.

**Case 07** – Asthma with Acute Exacerbation

**Clinical Record**: A 34-year-old patient with established asthma presents with wheezing and increased shortness of breath. The provider documents asthma with acute exacerbation. A nebulized bronchodilator treatment is administered in the clinic.

**Key findings**: Asthma with acute exacerbation; nebulized inhalation treatment administered.

**Code Assignment and Rationale**

 | Coding System | Code | Description  |
|---------|----------|-----------|
|ICD-10-CM | J45.901 | Unspecified asthma with (acute) exacerbation, when asthma severity/type is not further specified. | 
| CPT | 94640 | Pressurized or non-pressurized inhalation treatment for acute airway obstruction or sputum induction, when supported by the documented service.|

**Case 08** – Iron Deficiency Anemia, Unspecified

**Clinical Record**: A 41-year-old patient reports fatigue and weakness. Laboratory testing shows low hemoglobin and low ferritin. The provider documents iron deficiency anemia, unspecified. A complete blood count with automated differential is performed.

**Key findings**: Provider-confirmed iron deficiency anemia; CBC with automated differential performed.

**Code Assignment and Rationale**

| Coding System | Code | Description  |
|---------|----------|-----------|
| ICD-10-CM | D50.9 | Iron deficiency anemia, unspecified, because no more specific cause or subtype is documented. | 
| CPT | 85025 | Complete blood count with automated differential white blood cell count, when that test is performed. | 

**Coding Note**: Do not assume chronic blood loss or dietary iron deficiency unless documented. Verify the exact laboratory panel; CBC without differential is different.

**Case 09** – Chronic kidney disease, stage 3a

 **Clinical Record**: A 67-year-old patient attends follow-up for established chronic kidney disease. The provider documents CKD stage 3a. A blood specimen is collected for renal function testing. No acute kidney injury is documented.

 **Key findings**: CKD stage 3a; blood specimen collected for renal function testing.

 **Code Assignment and Rationale**

 | Coding System | Code | Description  |
|---------|----------|-----------|
| ICD-10-CM | N18.31 | Chronic kidney disease, stage 3a, matching the provider's documented stage. | 
| CPT | 36415 | Collection of venous blood by venipuncture, when venous blood collection is documented. | 

**Coding Note**: Use the documented CKD stage. Do not independently calculate or assign a stage from a laboratory value unless the applicable coding rules and provider documentation support it. Do not add acute kidney injury.

**Case 10** – Acute Gastritis Without Bleeding

**Clinical Record**: A 46-year-old patient presents with epigastric discomfort and nausea. After evaluation, the provider documents acute gastritis without bleeding. The treatment plan includes medication and dietary advice. No endoscopy, biopsy or other procedure is documented.

**Key findings**: Acute gastritis without bleeding; medical management; no procedure documented.

**Code Assignment and Rationale**

| Coding System | Code | Description |
|---------|----------|-----------|
| ICD-10-CM | K29.00 | Acute gastritis without bleeding, matching the documented diagnosis. | 

**Coding Note**: Do not assign a bleeding-related code or an endoscopy/biopsy CPT code when neither bleeding nor a procedure is documented.

**Coding Rationale – General Principles Applied** 
1. Code to the highest level of specificity supported by the provider's documentation and the applicable code set.
2. Do not infer a diagnosis, complication, organism, severity, anatomical site or procedure from symptoms or test results alone.
3. For outpatient coding, report confirmed diagnoses and follow the applicable rules for uncertain diagnoses and signs or symptoms.
4. A procedure code must match the service actually performed, including approach, views, method and required components.
5. HCPCS Level II drug units must be calculated using the code's stated dosage basis; in Case 05, 1,000 mg ÷ 250 mg per unit = 4 units.
6. Check code notes, inclusion/exclusion notes, sequencing instructions, modifiers, bundling edits and payer policy before real claim submission.

  **Challenges and Solutions**
  
  | Challenge | Example | Solution |
  |-----------|---------|----------|
  |Limited specificity in documentation| A diagnosis such as UTI without a stated site does not support coding a more specific urinary condition.| Use the code that matches the documented level of detail and identify what clarification would be needed.|
  |Distinguishing diagnosis from symptoms| Symptoms such as cough, fever, fatigue or abdominal pain may accompany a confirmed disease.| Code the provider-confirmed diagnosis when established; do not separately code integral symptoms unless rules or documentation support it.|
  |Selecting the correct procedure code | Different techniques or service components can change the CPT code, such as two-view versus other chest imaging or laparoscopic versus open surgery. | Match the code to the exact procedure, method, views and components documented. |
  |HCPCS drug-unit calculation | The HCPCS unit may represent a quantity smaller than the administered dose. | Calculate units from the code's dosage basis and verify the administered dose and payer instructions. |
  | Keeping code sets current | Code sets and guidelines are updated periodically. | Use the code set effective on the date of service and check official CMS/CDC publications and the current CPT reference. |
